# Metadata Standard

Every dataset in the Atlas must include:
- **Basic Info:** Name, Description, Domain, Tags.
- **Ownership:** Department, Data Owner, Contact.
- **Source:** Official URL, API Endpoint, Auth Method.
- **Legal:** License, Terms of Use, Attribution.
- **Technical:** Format, Schema, Spatial Reference, Update Frequency.
- **Quality:** Freshness, Completeness, Accuracy scores.

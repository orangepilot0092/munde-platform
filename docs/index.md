# Project Sahyadri

Project Sahyadri is an [Ee]nterprise-grade data and intelligence platform designed to build digital public infrastructure for Maharashtra. It transforms fragmented government and public data into trusted, reusable, and production-ready intelligence services.

## Key Features
- **Maharashtra Data Atlas:** Catalog of 300+ official datasets.
- **Geospatial Intelligence:** PostGIS-enabled spatial analytics.
- **AI-Ready:** Integrated RAG, OCR, and LLM orchestration.
- **Production-Grade:** Dockerized, tested, and documented.

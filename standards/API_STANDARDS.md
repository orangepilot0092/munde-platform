# API Standards

## Framework
- Use **FastAPI** for all REST APIs.
- Use **Pydantic V2** for request/response validation.

## Design
- RESTful principles.
- Versioning via URL path: `/api/v1/resource`.
- Consistent error responses using `HTTPException`.
- OpenAPI/Swagger documentation auto-generated by FastAPI.

## Security
- JWT-based authentication.
- RBAC for authorization.
- Rate limiting on all public endpoints.
